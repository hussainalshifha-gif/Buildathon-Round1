## 🚀 Getting Started

### Prerequisites
- Node.js installed
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/hussainalshifha-gif/Buildathon-Round1.git
cd Buildathon-Round1
```

2. Install server dependencies
```bash
cd server
npm install
```

3. Install client dependencies
```bash
cd ../client
npm install
```

### Running the App

Start the server:
```bash
cd server
npm start
```

Start the client:
```bash
cd client
npm start
```
